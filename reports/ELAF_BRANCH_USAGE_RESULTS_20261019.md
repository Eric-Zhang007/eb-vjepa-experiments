# E-LAF Step 2000：Future 分支使用诊断

本轮没有训练，也没有修改 checkpoint。32 个固定训练样本、每套 LIBERO 8 个；Action 时间固定 s=0.5，Delta 时间取十个区间中点 u=0.05,…,0.95。以下是同一批样本、相同噪声和原始监督目标下的配对比较。不是闭环成功率，也不是验证集泛化结果。

## 1. Action 是否依赖 Future 分支？

| 干预 | Action velocity MSE | 相对正常路径 |
|---|---:|---:|
| 正常 Joint Flow | 0.214463 | — |
| 跨样本打乱干净 Delta，保留各样本原噪声 | 0.215986 | +0.71% |
| 每层禁止 Action 读取 Delta | 0.217412 | +1.38% |
| 每层禁止 Action 读取 Current JEPA | 0.564316 | +163.13% |
| 每层禁止所有非 Delta token 读取 Delta | 0.228306 | +6.45% |

这些数据支持：当前 JEPA 状态对现有模型计算的影响明显；Delta 分支并非完全没有影响，但在本次诊断中，其影响远小于 Current。打乱真实 Delta 内容的影响较小。直接屏蔽 Action→Delta 的读取边不能排除经其他 token 中转，因此增加了最后一项全路径隔离。

不能把 +6.45% 直接当成 Future 物理信息带来的收益：隔离同时移除了 Delta 噪声、时间条件和 token 中转的影响，并改变了注意力归一化；打乱内容也有分布偏移。单独屏蔽 Current 的测试仍保留间接路径。当前结果尚不足以证明 Future 分支学到了不可替代的动力学信息，也不能否定辅助监督对训练权重的作用。

## 2. Delta 模型与无参数基线

解析预测器为 `-d_u/(1-u)`，与模型使用完全相同的 target、mask、mean reduction。零速度 MSE 在各时间点均为 1.003167。

| u | 模型 Delta MSE | 解析基线 MSE |
|---:|---:|---:|
| 0.05 | 0.073867 | 0.002075 |
| 0.15 | 0.068261 | 0.002592 |
| 0.25 | 0.064092 | 0.003329 |
| 0.35 | 0.061521 | 0.004432 |
| 0.45 | 0.062264 | 0.006190 |
| 0.55 | 0.065977 | 0.009247 |
| 0.65 | 0.077050 | 0.015286 |
| 0.75 | 0.104231 | 0.029962 |
| 0.85 | 0.185789 | 0.083226 |
| 0.95 | 0.548756 | 0.749038 |

模型已经明显优于零速度，但前九个时间点均不如简单解析去噪器。u=0.95 的胜出也不能单独证明动力学：该解析式在接近 1 时会放大残差误差，本身不是最优无条件预测器。此次是区间中点网格，不是每个区间内随机采样后的平均；没有取 u=1。

## 3. 干预可靠性和范围

最终采用原生 FlashAttention。全部 28 层均接受干预；无屏蔽包装与原模型 Action/Delta 输出完全一致。全路径隔离 Delta 后翻转 Delta 输入，Action 输出最大绝对差为 0。最初尝试的 SDPA 替换未通过输出一致性检查，已停止，其结果不纳入报告。

保留序列位置与其他输入。干预仅在诊断进程生效，不修改模型文件。全路径隔离排除 Delta 对其他 token 的读取影响，但仍然是离线、含真实未来插值的 velocity 诊断，不能替代从纯噪声开始的四步联合采样或 LIBERO 闭环比较。

## 4. 当前判断

优化已能稳定完成本次 2000 步短程训练；更长训练仍未验证。现在应把“Current JEPA 对当前模型有显著影响”和“Future 分支已学会有用动力学”分开：前者有明确敏感性证据，后者仍缺证据。无需据此添加 SIGReg 或扩大 slot 多样性目标。下一项若继续，应检验四步生成时隔离 Delta 对动作及闭环控制的影响。
